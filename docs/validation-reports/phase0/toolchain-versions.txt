## PATH note

The user Scripts folder containing `cmake.exe`, `ctest.exe`, and `pytest.exe` is not currently on the persistent Windows PATH. In this run, it was prepended to the current PowerShell process only. To do the same in a new PowerShell window without changing system settings:

```powershell
$env:PATH = "$env:APPDATA\Python\Python311\Scripts;$env:PATH"
cmake --version
ctest --version
pytest --version
```
